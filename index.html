🛠 How to Swap Airports

  1. Open your GitHub repo → config/airports.json
  2. Change the "active" array to your desired airports (max 3)
  3. Commit the change
  4. Go to Actions tab → Update LootRadar Arrivals → Run workflow
  5. Wait ~2 minutes, then refresh this page!
